# Mission Checklist - Dynamic To-Do List Application

A responsive and interactive To-Do List web application built for the Space Explorer crew using vanilla JavaScript and DOM Manipulation.

## Features

- **Dynamic Task Rendering:** Automatically displays tasks from an array data source.
- **Add New Tasks:** Add new mission tasks via an input form with input validation (prevents empty submissions).
- **Interactive State Toggle:** Click on any task text to mark it as completed (crossed out) or active.
- **Task Deletion:** Remove individual tasks using dedicated delete buttons.
- **Remaining Counter:** Real-time tracking of active tasks left to complete.
- **Empty State Handling:** Displays a notification message when all tasks are cleared.
- **Batch Actions:** Clear all completed tasks at once with a single click.

## Built With

- **HTML5:** Semantic markup and layout structure.
- **CSS3:** Modern styling with custom variables, Flexbox, and states (`.done`, `.hidden`, `.active`).
- **JavaScript (ES6+):** DOM Selection, Element Creation, Event Delegation, Arrays, and Loops.
